# Security & Network Engineering Portfolio

Muhammad Irfan Bin Mohd Kamil — Computer Science graduate targeting SOC Analyst, Cybersecurity Analyst, and Network Engineer roles.

This repository documents applied work in network design, defensive security tooling, and SIEM-based investigation, built to demonstrate practical capability alongside formal coursework and certifications (CCNA, Google Cybersecurity Certificate). Each project includes configuration files, diagrams, and a written investigation or design record.

## Contents

- **network-defense-lab/** — A segmented enterprise network built in GNS3/EVE-NG, defended with a firewall, IDS/IPS (Suricata), and EDR (Wazuh), validated with controlled attack simulation, and investigated using Splunk.
- **bots-v1-investigation/** and **bots-v3-investigation/** — Splunk Boss of the SOC investigations, documenting SPL queries and findings mapped to the Lockheed Martin Cyber Kill Chain and MITRE ATT&CK.
- **ai-triage-tool/** — A retrieval-grounded triage assistant for security alerts, built and evaluated against known-correct outcomes from the projects above.
